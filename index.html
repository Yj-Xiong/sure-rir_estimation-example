02

Rules that stay visible

Same JSONL contract, different channel guarantees.

A

Base RIR quality

Score every channel branch with NPM, RT30, RT60 and EDC before adding spatial metrics.

B

Spatial aggregation

IACC uses full, early, and late windows for exactly two channels. ITD, ILD, IPD, and DOA compare each chN with ch0, then average the pair errors into the reported score.

C

Provenance

Reference RIRs stay outside model inputs. Reports preserve pipeline identity, node IDs, and per-pair details.

05

Reproduce all page results

6 scenarios · 60 samples each · inference, scoring, assembly

Follow the complete workflow to regenerate the four monaural/binaural scenarios and two four-channel scenarios shown above. It selects both manifests, runs both model families on the cluster, scores all 360 model results, and builds candidate page data and frequency-band analysis for review.

  1. Prepare sources and selections

    60 legacy + 60 four-microphone rows

    Use the pinned evaluation engine, existing Rec-BIR model workspace and checkpoints, and both test manifests. Prepare dependencies in a CPU allocation; the exact prerequisites are in the reproduction guide.

    git clone https://github.com/Yj-Xiong/sure-rir_estimation-example.git
git clone https://github.com/Yj-Xiong/sure-evaluation.git
git -C sure-evaluation checkout 39b4146
export MODEL_PYTHON="/absolute/path/to/model-python-3.10"
"$MODEL_PYTHON" -m venv sure-evaluation/.venv
sure-evaluation/.venv/bin/python -m pip install --upgrade pip setuptools wheel
sure-evaluation/.venv/bin/python -m pip install -e 'sure-evaluation[audio]'
export EXAMPLE_ROOT="$PWD/sure-rir_estimation-example"
export RECBIR_ROOT="/absolute/path/to/Rec-BIR"
export DATA_ROOT="/absolute/path/to/variableMspacingFixedSNR_30scenes_260928"
python3 "$EXAMPLE_ROOT/scripts/select_legacy_demo.py" --dataset-root "$DATA_ROOT" --output "$EXAMPLE_ROOT/data/legacy_demo_selection.jsonl"
python3 "$EXAMPLE_ROOT/scripts/select_four_mic_demo.py" --manifest "$RECBIR_ROOT/NeuSIRI/data/four_mic_fixed_v2/test/test_manifest.jsonl" --output "$EXAMPLE_ROOT/data/four_mic_demo_selection.json"

  2. Run the four monaural/binaural scenarios

    Rec-RIR and NeuBIRE · 4090 queue

    The runner writes four 60-row manifests and RIR WAV sets. NeuBIRE monaural scores ch0 of its native two-channel estimate, matching the published waveform.

    export LEGACY_RUN="$RECBIR_ROOT/NeuSIRI/data/rir_demo_runs/legacy_60"
bash "$EXAMPLE_ROOT/example/submit_legacy.sh"

  3. Run the two four-channel scenarios

    Rec-RIR and NeuBIRE · 4090 queue

    Rec-RIR runs each channel separately. NeuBIRE runs two two-channel passes. Both combine four output paths using one shared crop anchor.

    export FOUR_RUN="$RECBIR_ROOT/NeuSIRI/data/rir_demo_runs/four_channel_60"
bash "$EXAMPLE_ROOT/example/submit_four_channel.sh"

  4. Score and assemble all six scenarios

    360 model results · CPU queue

    The four monaural/binaural scenarios follow the published one-second Rec-BIR/FiNS protocol. The two four-channel scenarios use the pinned SURE RIR bundle. The CPU job assembles the candidate JSON and computes frequency-band errors from full RIR WAVs.

    export SCORING_PYTHON="/absolute/path/to/scoring-python"
export SURE_EVAL="$PWD/sure-evaluation/.venv/bin/sure-eval"
export OUTPUT_ROOT="$RECBIR_ROOT/NeuSIRI/data/rir_demo_runs/page_report_60"
bash "$EXAMPLE_ROOT/example/submit_page_scoring.sh"

  5. Verify the candidate data

    six scenarios · 60 rows per scenario

    The scoring job checks case IDs, selected sample order, metric means, waveform shapes, finite scores and native-WAV frequency data before it reports success.

    python3 -m json.tool "$OUTPUT_ROOT/results.json" >/dev/null
python3 -m json.tool "$OUTPUT_ROOT/frequency_error.json" >/dev/null
python3 "$EXAMPLE_ROOT/example/test_example.py"

  6. Review and publish

    page data · frequency bands

    Compare the fresh candidate against the checked-in browser results. Review numeric changes before publishing both JSON files together.

    python3 "$EXAMPLE_ROOT/scripts/compare_page_results.py" --published "$EXAMPLE_ROOT/data/results.json" --candidate "$OUTPUT_ROOT/results.json"
install -m 644 "$OUTPUT_ROOT/results.json" "$EXAMPLE_ROOT/data/results.json"
install -m 644 "$OUTPUT_ROOT/frequency_error.json" "$EXAMPLE_ROOT/data/frequency_error.json"
node --check "$EXAMPLE_ROOT/app.js"
git -C "$EXAMPLE_ROOT" diff --check
